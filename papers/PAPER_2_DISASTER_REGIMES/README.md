## What this paper argues (analytical, not prose)

Disaster-displacement structure is determined by **physical geography**. Countries cluster into **6 distinct regimes** based on (a) which hazard channel dominates and (b) how event sizes distribute across years. Regime classification is stable on decadal timescales (physical geography doesn't move).

This paper is the **disaster-side parallel** to Paper 1's executive-aggrandizement typology — same meta-argument that "corpus heterogeneity is typology, not noise" applied to a different domain.
